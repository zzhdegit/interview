# 东南大学集成电路学院面试原题—数集_答案

## 1. 数字逻辑与 CMOS 门级基础

### Q1：组合逻辑和时序逻辑有什么区别？

组合逻辑的输出只由当前输入决定，不含存储状态，例如译码器、加法器、选择器。时序逻辑的输出由当前输入和历史状态共同决定，内部含触发器、锁存器或寄存器，例如计数器、状态机。组合逻辑关注逻辑功能和传播延迟；时序逻辑还必须满足时钟、建立时间、保持时间和复位等约束。

### Q2：锁存器和触发器有什么区别？为什么同步时序电路中尽量避免使用锁存器？

锁存器通常是电平敏感器件，使能有效时输入变化会直接影响输出；触发器通常是边沿敏感器件，只在时钟边沿采样输入。同步时序电路中尽量避免锁存器，是因为锁存器透明窗口会让时序路径跨级传播，容易产生竞争冒险、时序分析复杂、锁存器推断不明显，降低设计可控性。

### Q3：什么是建立时间和保持时间？违反后会发生什么？

建立时间是触发器时钟有效边沿到来前，数据必须保持稳定的最短时间；保持时间是时钟有效边沿之后，数据仍需保持稳定的最短时间。违反建立时间可能导致采样到错误值或亚稳态；违反保持时间也可能导致错误采样或亚稳态。建立时间通常限制最高频率，保持时间通常与最小路径延迟和时钟偏斜相关。

### Q4：Skew 和 Jitter 的区别是什么？它们如何影响时序裕量？

Skew 是同一时钟边沿到达不同寄存器的确定性时间差，主要来自时钟树和布线差异。Jitter 是时钟边沿相对理想位置的随机或周期性抖动，主要来自 PLL、电源噪声和时钟源。Skew 会改变发射端和接收端的相对采样窗口；Jitter 会缩小时序预算。两者都会减少 setup 或 hold 裕量。

### Q5：同步电路和异步电路各有什么优缺点？

同步电路由统一时钟控制，设计、验证和 STA 较成熟，可靠性高，但功耗和时钟树开销大，速度受全局时钟限制。异步电路不依赖统一时钟，理论上可低功耗、低延迟、无全局时钟偏斜问题，但设计和验证困难，容易受延迟、毛刺和握手协议影响。工程中主流芯片以同步设计为主，异步逻辑常用于跨时钟域或特殊接口。

### Q6：竞争与冒险产生的原因是什么？如何消除毛刺？

竞争是不同信号路径延迟不一致导致输入变化到达时间不同；冒险是竞争在输出端表现出的瞬时错误脉冲，即毛刺。消除方法包括加入冗余逻辑项、使用同步寄存器采样、避免多级组合逻辑竞争、平衡路径延迟、采用格雷码、对异步输入做同步处理。同步电路中只要毛刺不在采样边沿附近影响寄存器，通常不会造成最终错误。

### Q7：噪声容限是什么？它对数字电路可靠性有什么意义？

噪声容限表示数字门电路在不误判逻辑 0 或逻辑 1 的情况下可承受的最大噪声幅度。它由输入输出高低电平阈值决定，通常分为高电平噪声容限和低电平噪声容限。噪声容限越大，电路对电源扰动、串扰、工艺温度变化和地弹噪声越不敏感，可靠性越高。

### Q8：CMOS 反相器的基本工作原理是什么？

CMOS 反相器由 PMOS 上拉管和 NMOS 下拉管组成。输入为低电平时，PMOS 导通、NMOS 截止，输出被拉到高电平；输入为高电平时，PMOS 截止、NMOS 导通，输出被拉到低电平。稳态下理想情况下不存在从电源到地的直流通路，因此静态功耗很小。

### Q9：反相器的电压传输曲线有哪些关键点？

反相器电压传输曲线描述输出电压随输入电压变化的关系。关键点包括低输入高输出区、高输入低输出区、转换区、开关阈值 VM、VOH、VOL、VIH、VIL，以及由这些点定义的噪声容限。曲线越陡，增益越大，抗噪声能力通常越好。

### Q10：上拉网络和下拉网络在 CMOS 逻辑门中分别起什么作用？

上拉网络通常由 PMOS 构成，负责在输出应为 1 时把输出节点连接到 VDD；下拉网络通常由 NMOS 构成，负责在输出应为 0 时把输出节点连接到 GND。静态 CMOS 中上下拉网络互为对偶，确保任意稳定输入下输出要么被上拉、要么被下拉，避免稳定直通电流。

### Q11：为什么 CMOS 静态逻辑在稳态时理想静态功耗很小？

CMOS 静态逻辑稳态时，输出为高时下拉网络关断，输出为低时上拉网络关断，理想情况下 VDD 到 GND 没有直流导通路径，因此静态功耗很小。实际电路仍有泄漏功耗，包括亚阈值泄漏、栅泄漏、结泄漏等，先进工艺中泄漏可能不可忽略。

### Q12：动态功耗与电源电压、负载电容、翻转频率有什么关系？

动态功耗主要来自负载电容反复充放电，近似为 P = alpha C_L VDD^2 f，其中 alpha 为翻转活动因子，C_L 为负载电容，VDD 为电源电压，f 为时钟频率或翻转频率。降低动态功耗可从降电压、降频率、减小负载电容、降低翻转率入手。

### Q13：短路功耗是如何产生的？

短路功耗产生于输入信号翻转过程中，PMOS 和 NMOS 在一小段时间内同时导通，形成 VDD 到 GND 的瞬时直流通路。输入边沿越慢、负载越不匹配、器件尺寸越大，短路电流可能越明显。改善方法包括加快输入边沿、合理尺寸匹配和减少无谓翻转。

### Q14：传播延时和上升/下降时间有什么区别？

传播延时是输入变化到输出达到指定阈值之间的时间，通常分为 tPLH 和 tPHL。上升时间是输出从低电平上升到高电平某两个比例点之间的时间，下降时间是输出从高电平下降到低电平的对应时间。传播延时反映响应快慢，上升/下降时间反映边沿陡峭程度。

### Q15：扇入和扇出对延时和驱动能力有什么影响？

扇入是一个逻辑门的输入数量，扇入增大会增加串联器件数、输入电容和逻辑复杂度，通常使延时变大。扇出是一个门输出驱动的后级输入数量，扇出越大负载电容越大，输出转换越慢、延时越大。高扇出网络通常需要缓冲树或专门综合优化。

### Q16：如何用 NAND/NOR 实现任意组合逻辑？

NAND 和 NOR 都是功能完备逻辑门，配合反相即可实现任意布尔函数。做法是先把目标逻辑化为与或非形式，再用德摩根定律转换为 NAND-NAND 或 NOR-NOR 结构。CMOS 中 NAND/NOR 实现效率高，因此常以它们作为基本门构建复杂组合逻辑。

### Q17：译码器、编码器、选择器、加法器分别完成什么功能？

译码器把 n 位二进制输入转换成 2^n 个互斥输出；编码器把多个输入状态编码成较少位二进制输出；选择器根据选择信号从多路输入中选一路输出；加法器完成二进制加法，通常输出和位与进位。它们都是常见组合逻辑模块。

### Q18：如何用 LUT 实现四输入与门？

四输入与门可用一个 4 输入 LUT 实现：把 LUT 的地址输入接四个变量 A、B、C、D，把真值表中只有地址 1111 对应的存储位配置为 1，其余 15 个地址配置为 0。LUT 本质是小容量查找表，可实现任意输入数不超过 LUT 输入宽度的布尔函数。

### Q41：为什么数字电路中既需要半加器，也需要全加器？

半加器用于两个一位二进制数相加，输出和位与进位，但没有进位输入。全加器用于两个一位数加上低位进位输入，输出和进位输出。多位加法必须级联处理来自低位的进位，因此需要全加器；最低位或局部简单相加可用半加器。

### Q42：给定全加器真值表，如果某一路输入取反，输出逻辑会发生什么变化？

若全加器某一路输入取反，输出逻辑不再是原来的三输入加法关系。以 A 取反为例，sum = ~A xor B xor Cin，Cout = majority(~A, B, Cin)。可以理解为对输入编码进行了变换，真值表需重新计算，不能简单认为只把最终输出取反。

### Q97：什么是冒险中的静态冒险和动态冒险？

静态冒险是理论上输出应保持不变，但由于路径延迟不同产生短暂翻转；静态 1 冒险是应保持 1 却出现 0 脉冲，静态 0 冒险相反。动态冒险是输出本应翻转一次，却因多条路径延迟差异产生多次振荡。动态冒险常见于多级逻辑。

### Q98：如何通过卡诺图冗余项消除组合逻辑中的静态冒险？

用卡诺图消除静态冒险时，应在相邻的 1 单元之间加入冗余圈，使任意单个输入变化时始终至少有一个乘积项保持为 1。对与或表达式主要处理静态 1 冒险；对或与表达式可类似处理静态 0 冒险。冗余项不改变逻辑功能，但覆盖延迟空隙。

### Q99：为什么门级仿真中可能出现 RTL 仿真没有看到的毛刺？

RTL 仿真通常是零延迟或理想延迟模型，不体现真实门延迟和路径差异，因此看不到某些毛刺。门级仿真包含门延迟和 SDF 反标互连延迟，路径到达时间不同会暴露竞争冒险、复位释放和时钟门控毛刺等问题。

### Q100：CMOS 与门、或门为什么通常通过 NAND/NOR 加反相器实现？

CMOS 中直接实现与门或或门通常需要先实现 NAND 或 NOR 再加反相器，因为 NAND/NOR 的 PMOS/NMOS 串并结构更自然，晶体管数量和延迟更合适。复杂逻辑也常先用反相逻辑形式实现，再通过反相器得到目标极性。

### Q101：上拉网络和下拉网络的串并联关系如何由逻辑表达式确定？

在静态 CMOS 中，下拉网络 NMOS 按输出为 0 的逻辑条件构造：与关系通常对应串联，或关系对应并联。上拉网络 PMOS 是下拉网络的对偶网络：串并关系互换，并由输入取反特性实现互补逻辑。最终保证上下拉不会同时稳定导通。

## 2. RTL / FSM / 复位 / CDC / FIFO / 分频

### Q19：什么是有限状态机？Mealy 型和 Moore 型有什么区别？

有限状态机是由有限个状态、状态转移条件、输入和输出组成的时序逻辑。Moore 型输出只由当前状态决定，输出稳定但可能滞后一拍；Mealy 型输出由当前状态和输入共同决定，响应更快但更容易受输入毛刺影响。

### Q20：如何设计一个 1001 序列检测状态机？

设计 1001 序列检测器可建立表示已匹配前缀长度的状态：S0 无匹配，S1 匹配 1，S2 匹配 10，S3 匹配 100，检测到下一个 1 时输出命中。若允许重叠，命中后根据已输入的最后一位回到 S1；若不允许重叠，回到 S0。实现时需明确 Mealy 或 Moore 输出方式。

### Q21：阻塞赋值和非阻塞赋值有什么区别？各自适合描述什么电路？

阻塞赋值用 =，语句按顺序立即生效，适合描述组合逻辑中的中间变量计算。非阻塞赋值用 <=，右值在当前时刻采样，左值在时间步末统一更新，适合描述触发器和同步时序逻辑。一般规则是组合逻辑用阻塞赋值，时序逻辑用非阻塞赋值，避免仿真和综合语义不一致。

### Q22：always @(*) 和 always @(posedge clk) 分别适合写什么逻辑？

always @(*) 适合描述组合逻辑，敏感列表自动包含右值信号，要求在所有分支给输出赋值，避免推断锁存器。always @(posedge clk) 适合描述同步时序逻辑，如寄存器、计数器、状态机状态更新。若有异步复位，敏感列表还会包含复位边沿。

### Q23：同步复位和异步复位有什么区别？各自优缺点是什么？

同步复位只在时钟边沿生效，时序分析简单、释放安全、便于综合优化，但要求时钟存在才可复位。异步复位不依赖时钟，能立即复位，适合上电或异常场景，但释放时可能造成亚稳态或复位恢复/移除时间问题。常见做法是异步置位、同步释放。

### Q24：什么是亚稳态？跨时钟域信号为什么容易产生亚稳态？

亚稳态是触发器在建立/保持时间被违反时，输出短时间停留在不确定电平并延迟收敛的状态。跨时钟域信号与目标时钟没有固定相位关系，采样边沿可能恰好落在输入变化附近，因此容易引发亚稳态。亚稳态不能完全消除，只能降低传播概率。

### Q25：如何用两级触发器同步降低亚稳态风险？

两级触发器同步器把异步单 bit 信号先送入第一级触发器，再由同一目标时钟采样到第二级。第一级可能亚稳态，但在一个时钟周期内有时间恢复，第二级采到不稳定值的概率显著降低。该方法适用于慢变化单 bit 控制信号，不适合直接同步多 bit 数据总线。

### Q26：单 bit 信号和多 bit 总线跨时钟域分别怎么处理？

单 bit 跨时钟域常用两级触发器同步、脉冲展宽、toggle 同步或握手协议。多 bit 总线不能简单逐位同步，否则可能采到不一致数据；应使用异步 FIFO、握手锁存、格雷码指针、双口 RAM 或带有效信号的数据保持协议。核心是保证接收端看到的是同一时刻的一组数据。

### Q27：FIFO 在跨时钟域设计中有什么作用？

异步 FIFO 用于在两个不同时钟域之间传递多 bit 数据。写端按写时钟写入，读端按读时钟读出，内部通过读写指针和空满判断协调速率差。指针通常采用格雷码跨域同步，避免多 bit 同时变化导致错误判断。

### Q28：如何实现二分频、四分频和任意偶数分频？

二分频可用 T 触发器或寄存器每拍翻转实现；四分频可对二分频结果再二分频，或用计数器计 0 到 3。任意偶数 N 分频通常用模 N/2 计数器，每计满翻转输出一次，从而得到 50% 占空比的 N 分频时钟。

### Q29：奇数分频如何实现？占空比如何处理？

奇数分频可用模 N 计数器产生脉冲，但若要求 50% 占空比，需要结合上升沿和下降沿触发，分别产生相差半周期的波形再组合。若不要求严格 50% 占空比，可直接计数产生高低电平持续不同周期数的分频输出。实际设计中也可用 PLL/MMCM 生成精确时钟。

### Q82：异步复位释放为什么可能产生亚稳态？

异步复位释放与时钟无固定关系，释放边沿可能落在触发器采样窗口附近，违反恢复时间或移除时间，导致触发器亚稳态或不同寄存器在不同周期退出复位。常见处理是异步复位断言、同步复位释放，并对复位跨域进行同步。

### Q83：Gray 码为什么常用于异步 FIFO 的读写指针同步？

Gray 码相邻数值只变化一位，因此异步 FIFO 读写指针跨时钟域同步时，即使采样发生在变化附近，也最多只有一位存在不确定，降低多 bit 不一致导致空满误判的风险。同步后再转换或比较可提高可靠性。

### Q90：同步设计中为什么要尽量让所有触发器使用同一个时钟边沿？

同步设计中让触发器使用同一时钟边沿，可使数据发射和采样关系明确，便于 STA、CDC 控制和功能验证。若混用不同边沿，相当于引入半周期路径，时序裕量减少，对 duty cycle、skew 和 jitter 更敏感，也更容易产生约束错误。

### Q91：什么是时钟域？跨时钟域设计为什么是数字 IC 的常见风险点？

时钟域是由同一时钟或相位频率固定相关时钟驱动的一组时序逻辑。跨时钟域设计风险高，是因为源域信号到目标域采样边沿没有确定关系，可能产生亚稳态、丢脉冲、多 bit 不一致和协议错误。需要同步器、握手或异步 FIFO 等专门处理。

### Q92：单脉冲信号跨时钟域时，为什么可能会丢脉冲？可以如何处理？

单脉冲信号跨时钟域时，若脉冲宽度小于目标时钟周期或与目标采样边沿错开，目标域可能完全采不到，导致丢脉冲。处理方法包括脉冲展宽、转换为电平信号、toggle 同步、请求应答握手，或用异步 FIFO/事件计数器传递事件。

### Q93：异步 FIFO 中为什么要比较读写指针？空满标志如何理解？

异步 FIFO 通过比较写指针和读指针判断空满。读写指针相等通常表示空；写指针追上读指针并满足最高位翻转关系通常表示满。为了区分空和满，指针常扩展一位，并使用 Gray 码跨域同步，避免多 bit 变化造成误判。

## 3. FPGA / ASIC / IP / HLS / 项目与加速

### Q30：FPGA 设计流程一般包括哪些步骤？

FPGA 设计流程通常包括需求分析、架构设计、RTL 编写、功能仿真、约束编写、综合、布局布线、时序分析、生成 bitstream、板级调试和性能验证。复杂项目还包括 IP 集成、CDC 检查、资源功耗评估和硬件在环测试。

### Q31：综合后仿真和时序后仿真有什么区别？

综合后仿真使用综合得到的门级网表，主要检查 RTL 与综合后逻辑是否一致，但通常不含或只含估计延迟。时序后仿真在布局布线后网表中反标 SDF 延迟，可观察真实门延迟和互连延迟影响。前者偏功能等价检查，后者偏时序真实性和毛刺等问题检查。

### Q32：FPGA 和 ASIC 在设计流程、资源、时序、功耗上有什么区别？

FPGA 使用可编程逻辑资源，开发周期短、可重构、成本适合小批量，但频率、功耗和面积效率通常不如 ASIC。ASIC 是定制芯片，前期成本高、周期长、不可轻易修改，但性能、功耗、面积和单片成本更优。设计流程上 FPGA 重点是综合实现和板级验证，ASIC 还包括 DFT、物理设计、签核和流片。

### Q33：IP 核通常有哪些类型？软核、固核、硬核有什么区别？

IP 核可分为软核、固核和硬核。软核通常是 RTL 代码，可移植、可修改，但性能和面积依赖综合实现；固核通常是综合网表或布局相关描述，可优化部分性能但灵活性较低；硬核是已完成版图的物理宏，性能和面积确定，但工艺和平台绑定强。

### Q45：一个 RISC-V CPU 常见可以划分为哪几级流水？每一级主要完成什么功能？

典型 RISC-V CPU 可划分为五级流水：IF 取指，ID 译码和读寄存器，EX 执行 ALU 运算或地址计算，MEM 访问数据存储器，WB 写回寄存器。实际实现可能合并或拆分流水级，以权衡频率、面积、功耗和控制复杂度。

### Q46：Verilog 与 HLS C 语言建模在 FPGA/ASIC 项目中各有什么优缺点？

Verilog 直接描述硬件结构和时序，控制精确、效率高，适合关键模块和 ASIC/FPGA 底层设计，但开发周期长。HLS C 用高级语言描述算法，由工具综合硬件，开发快、适合算法加速探索，但生成结构可控性和 PPA 可能不如手写 RTL，且需要理解 HLS pragma 和存储/并行映射。

### Q47：为什么硬件加速项目中不能只讲模型精度，还要说明资源、延迟和功耗？

硬件加速项目最终落地受资源、延迟、吞吐率、功耗和带宽约束，不能只看模型精度。高精度模型若资源超限、延迟过高或功耗不可接受，就无法满足系统需求。说明资源、延迟和功耗能体现算法到硬件实现的完整权衡。

### Q48：ZYNQ 或 FPGA 部署神经网络时，训练集、验证集、测试集分别有什么作用？

训练集用于优化模型参数；验证集用于调参、选择模型结构和判断过拟合；测试集只在最终评估时使用，用于估计模型泛化性能。在 ZYNQ 或 FPGA 部署时，还需用测试集或真实数据验证量化后精度、吞吐率、延迟和资源占用。

### Q49：在数字识别或 CNN 项目中，如何判断并缓解过拟合？

过拟合表现为训练集准确率高而验证/测试集准确率明显低，或验证损失随训练继续上升。缓解方法包括增加数据、数据增强、正则化、Dropout、早停、减小模型复杂度、权重衰减、交叉验证，以及在硬件部署中注意量化和剪枝带来的泛化变化。

### Q50：CNN 中卷积层的作用是什么？相比全连接层有什么特点？

CNN 卷积层通过局部连接和权值共享提取空间局部特征，如边缘、纹理和形状。相比全连接层，卷积层参数量少、计算结构规则、能保留空间结构，并具有一定平移等变性。全连接层更适合全局特征融合和分类，但参数和计算开销大。

### Q51：为什么需要关注 PPA？数字 IC 中如何分别优化功耗、性能和面积？

PPA 即功耗、性能、面积，是数字 IC 设计的核心评价。优化功耗可用时钟门控、电源门控、多阈值、多电压、降低翻转；优化性能可缩短关键路径、流水线、并行化、使用高速单元；优化面积可资源复用、逻辑优化、减少寄存器和存储。三者通常相互制约。

### Q52：数字 IC 的典型设计流程包括哪些步骤？

数字 IC 典型流程包括规格定义、架构设计、RTL 编码、功能验证、逻辑综合、DFT 插入、形式验证、布局规划、布局布线、CTS、寄生参数提取、STA、功耗/信号完整性/物理验证签核、后仿真和流片。每一步都要围绕功能正确和 PPA 收敛。

### Q53：如果未来在 IC 方向中选择数字设计，应重点复习哪些课程和能力？

选择数字设计方向应重点复习数字逻辑、计算机组成、Verilog/SystemVerilog、时序分析、计算机体系结构、数字 IC 设计流程、EDA 基础、低功耗设计、验证方法学和脚本能力。还应能讲清一个 RTL 或 FPGA 项目的功能、架构、验证、资源、时序和 PPA。

### Q105：如果让你介绍一个数字 IC 项目，应如何说明功能、架构、验证和时序结果？

介绍数字 IC 项目时，应说明目标功能和应用场景、整体架构和模块划分、关键数据通路/控制逻辑、接口协议、验证方法和覆盖结果、综合实现结果、时序频率、资源或面积、功耗，以及遇到的问题和优化方法。重点是把功能正确性、架构合理性和 PPA 结果讲清楚。

## 4. 时序约束 / STA / 关键路径 / 流水线

### Q34：时序约束主要约束哪些路径？

时序约束主要约束寄存器到寄存器路径、输入端口到寄存器路径、寄存器到输出端口路径、跨时钟路径、时钟定义、时钟不确定性、时钟延迟、多周期路径和伪路径。合理约束是 STA 正确判断 setup/hold 是否满足的前提。

### Q35：什么是 setup slack 和 hold slack？

setup slack 是数据到达时间相对要求到达时间的裕量，通常等于要求时间减到达时间，正值表示满足 setup。hold slack 是数据最早变化时间相对保持要求的裕量，正值表示满足 hold。setup 违例常通过降频、优化组合逻辑、流水线解决；hold 违例常通过增加最小延迟或调整时钟树解决。

### Q36：什么是关键路径？如何优化关键路径？

关键路径是决定最高工作频率的最长时序路径，即 setup slack 最小或延迟最大的路径。优化方法包括减少组合逻辑级数、逻辑重构、插入流水线、寄存器重定时、提高驱动能力、降低负载、优化布局布线、使用更快单元或调整约束。

### Q37：流水线为什么可以提高频率？代价是什么？

流水线把长组合逻辑切分成多个较短阶段，中间插入寄存器，使每一级延迟减少，从而提高可达到的时钟频率和吞吐率。代价是寄存器面积和功耗增加、控制复杂度提高、单个数据的总延迟可能增加，还可能引入冒险、冲刷和停顿问题。

### Q43：建立时间、保持时间、传播延迟时间分别是什么？

建立时间是数据在采样边沿前需稳定的时间；保持时间是采样边沿后需继续稳定的时间；传播延迟是输入变化经过组合逻辑或触发器后引起输出变化所需的时间。触发器到触发器路径中，setup 检查关注最大传播延迟，hold 检查关注最小传播延迟。

### Q44：简述流水线的思想。流水线能提高什么性能，又会引入哪些代价？

流水线的思想是把一个复杂处理过程分为多个阶段，各阶段并行处理不同数据，并用寄存器隔开。它主要提高吞吐率和可运行频率，但会增加寄存器开销、控制复杂度、分支或数据相关处理成本，并增加单个任务的流水线延迟。

### Q78：什么是静态时序分析 STA？它为什么不需要输入激励？

STA 是静态时序分析，通过时序图和延迟模型枚举路径，计算数据到达时间和要求时间，检查 setup、hold 等约束。它不需要输入激励，因为采用静态传播和最坏/最好延迟分析覆盖可能路径，比动态仿真更适合大规模芯片签核。

### Q79：最大延迟约束和最小延迟约束分别对应 setup 检查和 hold 检查中的哪一类问题？

最大延迟约束对应 setup 检查，确保数据在下一个采样边沿前及时到达。最小延迟约束对应 hold 检查，确保数据不会在当前采样边沿后过早变化。setup 违例与路径太慢有关，hold 违例与路径太快或时钟偏斜有关。

### Q94：组合逻辑过深会如何影响最高工作频率？

组合逻辑过深会增加寄存器到寄存器路径的最大传播延迟，从而降低最高工作频率。最高频率近似受 Tclk >= Tcq + Tcomb + Tsetup + Tskew + Tuncertainty 限制。逻辑越深，Tcomb 越大，setup slack 越小。

### Q95：寄存器切分为什么可以改善关键路径？

寄存器切分是在长组合路径中间插入寄存器，把一个长路径拆成多个短路径，从而降低每一级组合延迟并改善关键路径。它可以提高最高频率，但会增加流水线延迟、寄存器面积功耗，并可能需要处理控制和数据对齐问题。

### Q96：为什么流水线级数增加后吞吐率可能提高，但延迟也会增加？

流水线级数增加后，每一级组合逻辑变短，时钟频率可提高，单位时间处理的数据量可能增加，因此吞吐率提高。但数据需要经过更多寄存器级，单个数据从输入到输出的周期数增加，控制冒险、冲刷和寄存器开销也增加。

### Q103：时钟树综合 CTS 的目标是什么？

CTS 的目标是构建时钟树，把时钟从源点分发到所有时序单元，同时控制 skew、latency、transition、功耗、抖动敏感性和布线拥塞。好的 CTS 能提升 setup/hold 收敛质量，并降低时钟网络功耗和不确定性。

## 5. DFT / 后端 / 低功耗 / 标准单元 / 仿真

### Q38：面积、速度、功耗三者通常如何权衡？

面积、速度、功耗是 PPA 的核心权衡。提高速度常需要更大单元、更多并行和流水线，可能增加面积和功耗；降低功耗可降压、门控、减少切换，但可能牺牲速度或增加控制面积；缩小面积可能增加延迟或功耗密度。设计需根据目标场景确定优先级。

### Q39：什么是 DFT？扫描链在芯片测试中有什么作用？

DFT 是可测性设计，用于提高芯片制造测试的可控性和可观测性。扫描链把触发器串接成可移位链，使测试机可以加载内部状态并观察响应，从而检测 stuck-at、transition fault 等故障。它提高测试覆盖率，但会带来面积、功耗、时序和测试模式安全性开销。

### Q40：数字 IC 后端中 CTS、布局布线、STA 分别做什么？

CTS 是时钟树综合，目标是把时钟低偏斜、低延迟、可控转换地分发到寄存器。布局布线负责放置标准单元和宏单元并完成互连布线。STA 是静态时序分析，在不施加具体输入激励的情况下遍历时序路径，检查 setup、hold、恢复、移除等时序约束。

### Q80：时钟门控为什么可以降低动态功耗？使用时要注意什么？

时钟门控通过在模块不工作时关闭其时钟，减少寄存器和时钟树翻转，从而降低动态功耗。使用时要保证门控信号无毛刺，并满足门控单元的建立/保持要求，通常使用库中的集成时钟门控单元。还需考虑测试模式、扫描链和时钟域一致性。

### Q81：多周期路径和伪路径分别是什么？为什么需要在约束中声明？

多周期路径是允许数据跨多个时钟周期到达的路径，需要在约束中放宽 setup，并相应处理 hold。伪路径是功能上不会被采样或不需要时序检查的路径，可从 STA 中排除。若不声明，工具会按默认单周期路径分析，可能产生虚假违例或错误优化。

### Q84：芯片测试中的 stuck-at fault 是什么？

stuck-at fault 是固定故障模型，假设某个节点永久卡在 0 或 1，不随输入变化。测试向量的目标是在故障点激活该故障，并把故障效应传播到可观察输出。它是数字芯片制造测试中最基础的故障模型之一。

### Q85：扫描链会给芯片面积、时序和测试覆盖率带来什么影响？

扫描链增加了触发器的扫描复用逻辑和链路连接，会增加面积和功耗，并可能影响关键路径时序。但它显著提高内部节点可控性和可观测性，从而提高测试覆盖率、降低测试生成难度。设计中需处理扫描时钟、测试模式和时序例外。

### Q86：标准单元库中通常包含哪些类型的单元？

标准单元库通常包含组合逻辑门、触发器、锁存器、缓冲器、反相器、时钟门控单元、多路选择器、加法相关单元、填充单元、天线修复单元、去耦电容单元、延迟单元和不同驱动强度/阈值版本的单元。库还提供时序、功耗、面积和版图信息。

### Q87：门级网表和 RTL 代码相比有什么区别？

RTL 代码描述寄存器传输级行为和结构，抽象度较高，便于设计和验证。门级网表是综合后的标准单元实例及连线，包含具体门结构，可用于形式验证、门级仿真、时序分析和后端实现。网表更接近真实硬件，但可读性和可维护性较差。

### Q88：后仿真中 SDF 文件的作用是什么？

SDF 文件用于在门级仿真中反标实际延迟，包括单元延迟、互连延迟、建立保持检查等。后仿真读取 SDF 后能更真实地观察时序效应、毛刺、竞争和复位释放问题。它通常来自布局布线后的寄生参数和时序计算。

### Q89：为什么低功耗设计中会使用多阈值单元、多电压域和电源门控？

多阈值单元用于在速度和泄漏之间权衡，关键路径用低阈值，非关键路径用高阈值。多电压域通过给不同模块使用不同电压降低功耗。电源门控在模块空闲时关闭电源以减少泄漏。它们都能降功耗，但会增加电源管理、时序收敛、隔离、保持和验证复杂度。

### Q102：数字后端布局中，为什么高扇出网络需要特殊处理？

高扇出网络驱动负载大，容易造成延迟大、转换慢、功耗高和信号完整性问题。在后端布局中需要缓冲树、复制驱动、负载分裂、合理布线和时序优化。时钟、复位、使能等高扇出信号尤其需要专门处理。

### Q104：芯片功耗分析中，峰值功耗和平均功耗分别有什么意义？

平均功耗表示一段时间内的平均能量消耗，关系到散热、电池续航和总体功耗预算。峰值功耗表示短时间最大功耗或电流需求，关系到 IR drop、电源完整性、电迁移、封装和稳压能力。两者都需要分析，不能只看一个。

## 6. 信号系统与 DSP

### Q54：单位冲激函数与任意函数卷积后结果是什么？

单位冲激函数是卷积的单位元，任意函数与单位冲激卷积结果仍为该函数：x(t) * delta(t) = x(t)，离散情形 x[n] * delta[n] = x[n]。若冲激有移位，则 x(t) * delta(t - t0) = x(t - t0)。

### Q55：单位阶跃函数之间卷积的结果如何理解？

连续时间单位阶跃 u(t) 与 u(t) 卷积为斜坡函数 r(t)=t u(t)。因为卷积积分为从 0 到 t 对 1 积分，t<0 时为 0，t>=0 时结果为 t。离散时间中 u[n] * u[n] 得到随 n 线性增长的序列，具体形式与阶跃定义有关。

### Q56：傅里叶变换的时移、尺度变换、微分和积分性质分别是什么？

傅里叶变换性质包括：时移 x(t-t0) 对应频域乘 e^{-j omega t0}；尺度变换 x(at) 对应 (1/|a|)X(omega/a)；时域微分对应频域乘 j omega；时域积分对应频域除以 j omega，并需考虑直流项。离散或工程频率 f 表达式形式会有 2pi 因子差异。

### Q57：帕塞瓦尔定理的物理意义是什么？

帕塞瓦尔定理说明信号在时域的能量等于频域能量积分，体现能量守恒。连续时间中 integral |x(t)|^2 dt = (1/2pi) integral |X(omega)|^2 d omega。它常用于从频谱角度分析能量、功率和误差。

### Q58：已知信号的奈奎斯特采样频率，如何判断 f(2t) 或平方信号的采样频率变化？

若 x(t) 的最高频率为 B，奈奎斯特采样频率为 2B。x(2t) 是时间压缩，频谱展宽 2 倍，最高频率变为 2B，采样频率需变为 4B。平方信号 x^2(t) 在频域相当于 X(f) 与自身卷积，带宽通常扩展到 2B，采样频率也需至少 4B；若具体频谱不同需按最高频率判断。

### Q59：分段函数如何利用定义式求拉普拉斯变换？

分段函数求拉普拉斯变换可按定义式分段积分：F(s)= integral_0^infty f(t)e^{-st}dt，将不同时间区间上的表达式分别积分后相加。也可用阶跃函数把分段函数重写为若干延迟项，再用时移性质求解。需要注意收敛域和初始时刻定义。

### Q60：实偶信号、实奇信号的傅里叶变换分别具有什么实虚和奇偶特性？

实偶信号的傅里叶变换为实偶函数；实奇信号的傅里叶变换为纯虚奇函数。更一般地，实信号的频谱满足共轭对称 X(-omega)=X*(omega)，偶对称部分对应实部，奇对称部分对应虚部。

### Q61：初值定理和终值定理的适用条件是什么？

初值定理通常用于求 f(0+)：f(0+) = lim_{s->infty} sF(s)，要求信号及变换满足相应存在条件。终值定理用于求 f(infty)：lim_{t->infty} f(t)=lim_{s->0} sF(s)，要求系统稳定，且 sF(s) 的极点除可能在原点外都在左半平面；若存在右半平面极点或虚轴非零极点则不能用。

### Q62：如何根据 s 域极点位置判断连续系统稳定性？

连续时间 LTI 系统稳定要求系统函数 H(s) 的所有极点位于左半平面。极点在右半平面会导致发散；极点在虚轴上通常临界稳定或不满足 BIBO 稳定，若有重极点则发散。极点离虚轴越近，响应衰减越慢；越靠左，响应衰减越快。

### Q63：如何利用 z 变换求解线性常系数差分方程？

利用 z 变换求解差分方程时，先对方程两边做 z 变换，结合初始条件处理移位项，解出 Y(z)，再做部分分式展开并结合 ROC 求逆 z 变换。零初始条件下可直接由输入输出关系得到系统函数 H(z)=Y(z)/X(z)。

### Q64：给定差分方程时，如何判断系统的线性、时不变、因果和稳定性？

线性看是否满足叠加性；时不变看输入延迟是否只导致输出同样延迟；因果看输出是否只依赖当前和过去输入；稳定看有界输入是否产生有界输出。对 LTI 差分系统，因果性通常要求系统函数 ROC 在最外极点之外，BIBO 稳定要求单位圆包含在 ROC 内。

### Q65：若 y(t)=x(t)*h(t)，如何分析 y(2t) 与原卷积结果的关系？

若 y(t)=x(t)*h(t)，则 y(2t) 是卷积结果的时间压缩，不等于 x(2t)*h(2t)。根据卷积尺度性质，x(2t)*h(2t) = 1/2 y(2t)（连续时间，尺度因子为 2）。因此 y(2t)=2[x(2t)*h(2t)]。离散情形需谨慎，因为抽取会引入不同关系。

### Q66：z 变换的收敛域 ROC 有什么意义？为什么求逆 z 变换时必须结合 ROC？

ROC 表示 z 变换收敛的 z 平面区域。相同代数表达式配合不同 ROC 可对应不同时间序列，例如因果、反因果或双边序列。求逆 z 变换必须结合 ROC 才能唯一确定序列，同时 ROC 也决定系统的因果性和稳定性。

### Q67：因果系统和稳定系统对 H(z) 的极点和 ROC 有什么要求？

因果 LTI 系统的 H(z) ROC 位于最外极点之外；稳定系统要求单位圆包含在 ROC 内。若系统既因果又稳定，则所有极点必须在单位圆内。若极点在单位圆上，通常不满足 BIBO 稳定。

### Q68：FIR 系统为什么可以看作全零点系统？

FIR 系统冲激响应长度有限，系统函数 H(z) 是 z^{-1} 的有限多项式，分母没有非平凡极点，因此常称为全零点系统。严格说可能在 z=0 处有由延迟形式引入的极点，但从滤波器结构和稳定性角度通常视为全零点。

### Q69：最小相位系统和全通系统分别有什么特点？

最小相位系统在因果稳定条件下所有零点都位于单位圆内，具有最小相位延迟，并且逆系统也稳定。全通系统幅频响应恒为 1，只改变相位，零点和极点关于单位圆成倒易共轭关系。二者常用于相位均衡和滤波器分解。

### Q70：广义线性相位 FIR 系统的零点分布有什么特点？

广义线性相位 FIR 系统的冲激响应具有对称或反对称特性，因此其零点分布具有成对关系：若 z0 是零点，则 1/z0 通常也是零点；实系数还要求共轭零点同时存在。因此零点常以共轭和倒易成组出现。

### Q71：模拟信号变为数字信号通常经历哪几个环节？采样和量化分别解决什么问题？

模拟信号变为数字信号通常经历抗混叠滤波、采样、量化和编码。采样把连续时间信号变为离散时间信号，解决时间离散化问题；量化把连续幅度映射到有限电平，解决幅度离散化问题；编码把量化电平表示为二进制码。

### Q72：影响频率分辨率的因素有哪些？窗函数形状会带来什么影响？

频率分辨率主要由观测时间长度和 DFT 点数决定，本质上约为 fs/N。观测时间越长，频率间隔越小。窗函数影响主瓣宽度和旁瓣高度：主瓣越窄分辨率越高，旁瓣越低泄漏越小，但二者通常存在权衡。

### Q73：用循环卷积计算线性卷积时，点数应满足什么要求？

用循环卷积计算长度为 L 的序列和长度为 M 的序列的线性卷积时，循环卷积点数 N 至少满足 N >= L+M-1。若 N 小于该值，线性卷积结果会发生时域混叠。工程中常通过补零到足够长度后用 FFT 加速卷积。

### Q74：DIF-FFT 两点蝶形运算的基本结构是什么？

DIF-FFT 即频率抽取 FFT，两点蝶形通常先对输入做加减运算，再将差值支路乘旋转因子。基本形式为上支路 a+b，下支路 (a-b)W_N^k。DIF 的输入通常为自然顺序，输出可能为倒位序，具体取决于实现结构。

### Q75：DFT 和 FFT 的运算量有何差别？给定点数时如何估算复杂度？

直接 DFT 的复乘和复加复杂度约为 O(N^2)，FFT 利用分治把复杂度降为 O(N log2 N)。基 2 FFT 通常需要约 (N/2)log2N 次复乘和 Nlog2N 次复加。点数越大，FFT 相比 DFT 的优势越明显。

### Q76：数字滤波器设计中，低通、高通、带通、带阻之间如何做频率变换？

数字滤波器频率变换可先设计原型低通滤波器，再通过频率映射得到高通、带通或带阻。IIR 常用模拟原型加双线性变换或频率变换；FIR 可通过谱变换、调制、窗函数或 Parks-McClellan 方法设计。关键是把目标通带、阻带边缘映射到原型滤波器指标。

### Q77：给定系统结构图时，如何写出系统函数 H(z)？

给定系统结构图时，应根据加法器、延迟单元和乘法器写节点方程，利用 z^{-1} 表示单位延迟，列出输入 X(z)、输出 Y(z) 的关系，整理得到 H(z)=Y(z)/X(z)。反馈结构会形成分母，前馈结构形成分子。注意信号方向和延迟位置。
